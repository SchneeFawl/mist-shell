# DESCRIPTION
I am creating a custom Hyprland shell using Quickshell on Arch Linux. I have decided to name it mist-shell. This shell is going to contain Hyprland config  files (in lua, based on the latest update v0.55.0), custom bar (no waybar, only quickshell), custom menu for keybinds, a simple settings menu for configurability and much more.

# MOTIVE
The main motive of this shell is easy customizability, usability and performance.
Two persons are going to work on this project, one is somewhat experienced (person 1, willing to learn more) and the other person is starting out (person 2). To be specific, I am the person 1

# REFERENCES
I am taking inspiration from illogical-impulse (end4-dotfiles), Ambxst (Ax-Shell), Nucleus and many more. I am going to be trying out Fabric (for desktop widgets) because I can code in Python comfortably.

# PROGRESS
Till now, a basic bar has been created.
The CenterModule of the Bar needs to be dyanmic just like in Ambxst, when the mouse is hovered, it will extrude into a dashboard like widget.
The overall Hyprland config using Lua is complete except for animations. Theme support will be added on later.
